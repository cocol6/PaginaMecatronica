# Meca Presupuestos

Generador de presupuestos en HTML, CSS y JavaScript para equipos industriales, informáticos y de conectividad.

## Uso

Abrí `index.html` en un navegador. Ingresá el nombre del cliente y completá hasta cinco productos con cantidad y precio unitario. El catálogo es orientativo y el usuario puede cargar el precio cotizado para cada producto.

El cálculo discrimina IVA al 21%. Ahora 12 divide el total con IVA en doce cuotas sin interés. Ahora 18 aplica 75% de interés al total con IVA y lo divide en dieciocho cuotas. Los botones **Imprimir presupuesto** y **Exportar a PDF** abren el diálogo de impresión del navegador; elegí una impresora o **Guardar como PDF**.

## Archivos

- `index.html`: estructura y contenido.
- `styles.css`: estilos adaptables a pantallas e impresión.
- `app.js`: catálogo, filas de productos, validación y cálculos.

No requiere instalación ni dependencias de JavaScript. La tipografía web usa Google Fonts y cuenta con fuentes de respaldo si no hay conexión.
